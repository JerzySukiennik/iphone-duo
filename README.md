# iPhone Duo — simulator

Localhost simulator of Apple's foldable iPhone Duo (iOS 27). Vanilla ES modules, no build.

    python3 serve.py 8555      # then open http://localhost:8555

**Hardware** — drag the left edge or use the toolbar to fold/unfold (spring hinge), Rotate, Laptop, Tent, Flip (rear cameras + outer display), Night Sky / Star White. Side button (right edge): wake / Touch ID unlock / sleep; passcode 1234. Volume + Action + Camera Control buttons work.

**Keys** — `O` open/close · `R` rotate · `L` laptop · `T` tent · `B` flip · `P` side button · `Esc`/`H` home.

**Apps** — Camera (real webcam, photo/video/portrait/Smart Take/Duo Preview), Photos, Reels, Messages, Music, Safari, Clock, Calendar, Weather, Notes, Settings, Phone, Calculator.
